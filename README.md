# NotePad Pro - Android App

📝 تطبيق محرر نصوص عربي متقدم للأندرويد مكتوب بلغة Kotlin

## الميزات الرئيسية
- ✅ محرر نصوص متقدم مع دعم كامل للعربية (RTL)
- ✅ إنشاء وحفظ وفتح ملفات نصية
- ✅ بحث واستبدال متقدم
- ✅ تنسيق النصوص (ترتيب، تنظيف، تحويل)
- ✅ وضع داكن وفاتح
- ✅ إعدادات قابلة للتخصيص
- ✅ حفظ تلقائي
- ✅ إعادة/تراجع

## المتطلبات
- Android Studio 2023.1 أو أحدث
- Android SDK 24 (Nougat) أو أحدث
- Kotlin 1.9+
- Java 17+

## البدء
```bash
git clone https://github.com/MainHub-Code/NotePad-Pro-Android-App.git
cd NotePad-Pro-Android-App
```

## البناء
```bash
./gradlew build
```
